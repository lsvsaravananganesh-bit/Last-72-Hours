# Prompt & Play — Competition Structure

## Source requirements
The official Prompt & Play guidelines describe an open-ended prompt-based game build challenge. The game may use any concept, genre, style, or platform, but it must be original and innovative. AI prompting is expected and the prompts used to build the game must be disclosed.

## Current game
**LAST 72 HOURS — Emergency Operations Simulation**

Core player fantasy:
> You do not fight the cyclone. You prepare the city to survive it.

The player is the Emergency Operations Commander of the fictional city of Surya Nagar.

## Core gameplay loop
1. Receive changing intelligence.
2. Travel through the city.
3. Reach an active emergency.
4. Interact with civilians, vehicles, infrastructure, or mission targets.
5. Issue an emergency command.
6. Observe civilian, traffic, medical, infrastructure, and weather consequences.
7. Respond to newly generated emergencies.
8. Continue until landfall and assess the outcome.

## Game systems
- Open-world top-down city
- Player movement and emergency vehicles
- Civilian behaviour and distress calls
- Ambulance, police and fire crew AI
- Dynamic fires and inaccessible buildings
- Flooding and traffic
- Emergency missions
- Mission consequences
- Resource management
- Public trust, panic and misinformation
- Hospital and shelter pressure
- Tactical map
- Interactive tutorial
- Mission tracker and navigation HUD

## UX structure
The player should always see:
- What is happening
- What the current objective is
- Where to go
- What key to press
- What changed after the decision

The first-time flow is:
**Tutorial → First Warning → Evacuation Run → Bridge Collapse → Hospital Crisis → Shelter Overload → Dynamic emergencies → Landfall**

## Originality boundary
The game uses an original fictional city, original characters, original missions, original emergency systems and original visual presentation. It is not a reproduction of an existing commercial game's characters, map, story, assets, or branding.

## Competition submission alignment
The official guidelines require one PDF with exactly two pages:
- Page 1: game concept, gameplay and originality
- Page 2: complete prompts used, in development order
Team name and members must appear at the top of Page 1.

**Important:** the official guidelines file supplied for this project does not specify a particular game theme beyond the open-ended game-build challenge; it specifies a theme-reveal date of 22 September. Therefore this project is being structured around the documented freedom to choose an original game concept rather than inventing an undocumented theme requirement.
